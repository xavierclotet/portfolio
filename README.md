# Portfolio · Xavi Clotet

Web personal con casos de estudio de mis proyectos: producto con LLM, desarrollo con agentes y
aplicaciones web en producción. Español e inglés.

Hecha con [Astro](https://astro.build), estática y sin dependencias de UI.

```sh
npm install
npm run dev      # servidor de desarrollo
npm run verify   # tipos + build
```

Los casos de estudio están en `src/content/projects/<es|en>/`.
